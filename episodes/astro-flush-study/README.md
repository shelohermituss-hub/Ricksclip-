# astro-flush-study: PRIVATE EXERCISE (user, 2026-11-22)

Reproduce the first 40 s of Rick's "Why Astronauts Can't Flush in Space" with our pipeline and cast, to learn his
picture, camera, timing and motion. NEVER published, never used in a film. Rick's frames, video and sound stay in
`references/look_match/astro_flush/` (git-ignored). This folder holds only our own build (code, plans, our renders).

Reference: 1080x1920, 30 fps, 40.0 s = 1200 frames (frame N of the reference = file `ref/all/f_%04d.jpg` N+1).
Narration word times: `refs/words_ref.json` (faster-whisper on the reference sound).
