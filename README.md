# Ricks Clips Animation Skill V1.2 (premium, Viral Shorts by CB)

A Claude Code skill that makes Ricks Clips style 3D cartoon true-story Shorts on your own PC: flat inked characters acting in a detailed three.js world, one flowing camera, voice, captions, a full sound track and a colour grade. No AI video generator.

**Start with [START_HERE.md](START_HERE.md).** New in this version: [WHATS_NEW_V1.2.md](WHATS_NEW_V1.2.md).

| Path | What it is |
|---|---|
| `START_HERE.md`, `INSTALL.md`, `START_FILM_PROMPT.md` | Read order, setup, the prompt for every film |
| `CB_RULES.md`, `SKILL.md` | The rule book and the how-to |
| `SOUND_AND_MUSIC.md`, `TOKEN_SAVING.md` | Music and sound effects; quality tiers and token rules |
| `agents/` | 17 helpers: writer, creative director, camera director, set builder, animator, sound designer, editor, judge and more |
| `tools/` | Installer, plan check, frame checks, camera-safe validator, measuring tools, voice tools, token report |
| `templates/threejs_film/` | The film kit: storyboard, animatic, final frames on your graphics card |
| `templates/vector2d_characters/`, `templates/motion_styles/` | The character rig, cast, outfits, faces and the motion library |
| `templates/sound_kit/` | Library index, sound search, cue list, the mix |
| `templates/pieces/` | Proven effect and staging pieces (power effects, transitions) |
| `references/` | The measured numbers, the written style reports and the camera move library (no frames) |
| `episodes/fake-surgery/`, `episodes/lightning-spear/` | Two worked example films (text and code) |
| `rules/` | Parked rules (Blender) and the rule-slice index |

Not included: reference frames or videos from other channels, sound and music libraries, BlenderKit models, a voice account.
