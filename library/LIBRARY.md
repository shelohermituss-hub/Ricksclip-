# ASSET LIBRARY — search here before building anything (CB_RULES section 3, "THE ASSET LIBRARY")

How to use: `library/README.md`. Paths are from the skill root. Nothing heavy is copied here: each row points to the script that builds the
item and the log that re-downloads its sources. `*.blend` / `*.glb` / downloads are git-ignored and rebuilt by those scripts.
Abbreviations: **ST** = `episodes/_style_test/` (the Rick-recipe front-yard still, 2026-11-21); **YFT** = `episodes/yellow-fire-trucks/`
("Why Fire Trucks Turned Yellow"); **AP** = `YFT/assets_prod/`; **PE** = `episodes/plane-eater/`. "BL" = Blender (final render), "kit" = three.js staging.
**IN-FILM ONLY** in "known faults" = the script reads its film's files by fixed paths; the list after it is what must change to reuse it.

Columns: name | what it is | made for (film) | build script / file | source and licence of downloads | scale | how to adapt (parameters) | known faults | preview picture
